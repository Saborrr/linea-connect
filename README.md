# Linea Connect / Линия

Открытый VPN-клиент для Android, iPhone и Mac на основе
[Hiddify](https://github.com/hiddify/hiddify-app). Рабочее имя: Linea.

**Статус: исходники начальной версии. Установочные сборки и работа на устройствах
в этой работе не подтверждены. Публичный форк: https://github.com/Saborrr/linea-connect.**

## Что изменено

- Новый главный экран: подключение, текущий профиль, задержка и счётчики трафика.
- Основные действия доступны сразу; дополнительные параметры раскрываются отдельно.
- Автовыбор группы `urltest` из текущей подписки через API штатного ядра.
- Экспорт журнала и копирование строки преобразуются в обезличенные коды событий.
  Полные сообщения ядра, URL подписок и неизвестные поля в отчёт не попадают.
- Отдельная проверенная политика переключения с гистерезисом, cooldown и сбросом
  измерений после смены сети. Пока не подключена к фоновым VPN-службам.
- Название, значки, deep link `linea://` и application ID `io.github.saborrr.linea`.
- Отключены отправка crash-report и проверка обновлений исходного приложения.
- Добавлены проверки политики и приватности экспорта; отдельный GitHub Actions
  workflow для ручной сборки Android. Прежние workflows сохранены как справочные.

## Подключение к своему серверу

В клиент добавляется персональная подписка или ссылка подключения из 3x-ui.
Пароль администратора панели и SSH-ключи приложению не нужны.
Действующих адресов, подписок и ключей сервера пользователя в проекте нет.

3x-ui является серверной панелью. Наличие протокола в новой панели не означает,
что конкретная клиентская библиотека и текущий сервер уже совместимы с ним.
Матрица и непроверенные функции: [PROTOCOLS.md](docs/linea/PROTOCOLS.md).

## Ограничения

- Автовыбор узла ядром не равен определению белых списков оператора.
- Нельзя гарантировать доступ к IP, который оператор не разрешает. Нужны заранее
  добавленные и действительно доступные резервные маршруты.
- Фоновое исполнение новой адаптивной политики в iOS extension/Android service
  ещё не реализовано. Тесты политики не являются испытанием сетевого обхода.
- Шифрование унаследованных файлов профилей, проверки DNS/IPv6 leaks,
  kill switch и установка на реальные устройства входят в следующие этапы.

## Проверка отдельных модулей

```sh
dart tool/linea_checks.dart
```

Проверка не требует Flutter, pub-пакетов, сетевого доступа или реквизитов сервера.
