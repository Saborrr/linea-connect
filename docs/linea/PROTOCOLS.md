# Протоколы и совместимость

Дата проверки документации: 22.10.2026. Проверки реальных подключений не выполнены.
Версии панели и ядра сервера пользователя не проверялись на VPS. Их необходимо
подтвердить перед интеграционными испытаниями.

| Семейство | Требуемый путь | Текущее состояние проекта |
| --- | --- | --- |
| VLESS + TLS / REALITY / Vision | Совместимое ядро, серверный inbound, согласованные параметры | Унаследованный путь Hiddify; требуется испытание конкретной пары версий |
| VLESS + XHTTP | Xray-совместимый движок и транспорт | Заявлен в актуальных материалах Hiddify; наличие в собранном native core и взаимодействие с сервером не проверены |
| VMess / Trojan / Shadowsocks / SS2022 | Соответствующий движок | Унаследованный импорт и ядро; испытания конкретных конфигураций ожидаются |
| Hysteria / Hysteria2 / TUIC | Совместимый QUIC-движок и сервер | Упомянуты в документации Hiddify; ограничения UDP и версия TUIC проверяются отдельно |
| WireGuard | WireGuard endpoint в ядре | Унаследованный путь, не испытан на сервере пользователя |
| AmneziaWG, включая новые версии | Отдельный совместимый движок и параметры той же версии на сервере | Не реализовано в изменениях Linea; не объявляется поддержанным |
| WebSocket / gRPC / HTTPUpgrade / TCP Raw | Транспорт внутри основного протокола | Это не отдельные VPN-протоколы; требуется проверка конкретного ядра и импорта |
| mKCP, новые режимы VLESS Encryption, ECH, MASQUE | Зависит от версии и сборки ядра | Нельзя обещать по названию клиента; отдельные задачи проверки/интеграции |
| AnyTLS / Naive / ShadowTLS / SSH | Дополнительные адаптеры ядра и совместимый сервер | Возможности кандидатов; не подтверждены для данной сборки и сервера |
| HTTP / SOCKS | Удалённый proxy-outbound; шифрование не гарантировано самим SOCKS/HTTP | Не включать открытые нешифрованные подключения по умолчанию |
| MTProto | Telegram proxy | Не универсальный VPN для трафика всего телефона; отдельная интеграция при необходимости |
| TUN / Mixed / Dokodemo-door / Tunnel | Локальный или серверный способ приёма трафика | Не следует превращать весь список inbound панели в список клиентских протоколов |

Текущий README 3x-ui включает также AmneziaWG, TUIC v5, Hysteria2 и MTProto.
Это не означает их наличие в старой установленной панели или в закреплённой
клиентской библиотеке. Автообновление production-ядра без проверки совместимости
не предусматривается.

Нужен реестр capabilities: протокол, транспорт, security, версия движка,
платформа, ограничения импорта и результат интеграционного теста. До его реализации
таблица служит планом проверки, а не рекламой уже работающей поддержки всего.
