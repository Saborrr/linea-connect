## Не подтверждено

- Работа нового интерфейса на экране устройства, отсутствие переполнений при масштабировании.
- Собственная release-подпись Apple, notarization и установка на устройства; установочный IPA.
- Соединение с сервером пользователя и фактическая поддержка каждого протокола.
- DNS/IPv6 leaks, kill switch, энергопотребление и поведение при смене сети.
- Исполнение новой адаптивной политики в Android VPN service / iOS extension.
- Надёжное распознавание признаков белых списков.
- Шифрование унаследованной базы и файлов конфигураций профилей.

## Где выполнялись проверки

Отдельные модули проверялись локально напрямую Dart VM без Flutter и сетевых
запросов, а также в GitHub Actions. Полные 203 Flutter-теста и компиляция Android
выполнены в GitHub Actions. Результаты перечисленных выше запусков доступны
в журнале CI; они не доказывают работоспособность туннеля на реальном устройстве.
iOS и macOS компилировались на macOS runners в GitHub Actions без сертификатов
и подписания для распространения.

## Критерий выпуска

Полная сборка и тесты в GitHub Actions; подпись своими ключами; реальные устройства
Android/iPhone/Mac; собственная тестовая подписка; сценарии ограничения сети,
недоступного VPS, недоступной подписки, истёкшего профиля, captive portal,
Wi-Fi/mobile handover и ручного отключения; проверка приватности и утечек.
До этого проект является подготовленной веткой разработки.

## Обновление 0.2.0, 22.10.2026

Локально проверены:

- Добавление нескольких профилей, точное сравнение адресов подписок,
  сохранение выбранного профиля и обновление одной записи без потери остальных.
- Flutter-интерфейс при ширине 320, 390 и 768 и масштабе шрифта 1, 1.5 и 2.
  Полные подписи импорта и прокрутка не дают RenderFlex overflow.
- Обработка ошибок native-потока и освобождение ожидающих вызовов при закрытии.
- Сохранение обезличенной диагностики после перезапуска и пропуск оборванной записи.
- Native AWG 2.0 и 3.1: импорт `.conf`/query, передача параметров в IPC,
  принятие S3/S4 официальным device и зашифрованный TCP/UDP loopback.

Приложенный пользователем старый экспорт содержал только `error/other` без
исходных сообщений и stack trace. Он не позволяет установить точную причину
вылета. Исправлены обнаруженные дефекты двойного закрытия экрана выбора,
повторного создания stream listener и запросов к остановленной VPN-службе.
Это не подтверждение того, что именно они вызвали сообщённый вылет.
Схема диагностики 2 добавляет места ошибок и сведения Android о завершении процесса.

Установка обновления, переподключение на реальном телефоне, совместимость
конкретного сервера и работа под ограничениями оператора остаются проверками
на устройстве. Превью в README используют тестовые данные.
